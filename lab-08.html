Technical concept

DLP: Dictionary → Engine → Policy

Think of Zscaler DLP as three layers: a dictionary detects sensitive content, an engine combines detection logic, and a DLP policy decides when and what action to take.

ContentFile / text / upload
→
DetectDictionaryWhat sensitive data looks like
→
CombineDLP EngineOne or more dictionaries + logic
→
DecideDLP PolicyWho / where / channel / action
→
EnforceAllow / Block / Notify
DLP dictionaries

Detection building blocks

Predefined dictionaries cover common data types such as credit-card or government-ID patterns. Custom dictionaries can use Patterns & Phrases, Exact Data Match (EDM), Indexed Document Match (IDM), or information-protection labels.

DLP engines

Collections of dictionaries

An engine references one or more dictionaries and can combine them with logic and thresholds. Policies reference the engine, not the individual dictionary.

DLP policies

Context + enforcement

The policy applies the engine to selected traffic/users/apps and determines the response—such as blocking the transfer and showing an end-user notification.

How this maps to Lab 8

The lab uses the predefined Credit Cards dictionary inside a custom Sensitive Data engine. The DLP rule then references that engine and blocks the test upload when the match threshold is met.

8.1

Protect PII Information for Data in Motion

Build a simple DLP policy around the predefined Credit Cards dictionary and prove that it blocks a test upload.

Current Experience Center navigation
Data Security

Fastest option: use Search menu and search for Dictionaries and Engines / Data Loss Prevention.

  1. First confirm SSL Inspect All is Enabled under
    Internet Access›Policy›SSL/TLS Inspection
    . DLP needs visibility into encrypted web traffic.
  2. Open Data Security and use Search menu for Dictionaries and Engines. Review the predefined Credit Cards dictionary, then switch to the DLP Engines tab.
  3. Create a DLP engine:
    SettingValue
    NameSensitive Data
    ExpressionAll
    Predefined DictionaryCredit Cards
    Violation Threshold1
    DescriptionCredit Card Number and Sensitive Data Violation
    Save and activate.
  4. In Data Security, use Search menu for Data Loss Prevention and add a DLP rule.
  5. Configure:
    SettingValue
    Rule Order1
    SeverityHigh
    Rule NameData Violation Rule
    Rule StatusEnabled
    Content MatchingDLP Engine
    DLP EngineSensitive Data
    Data TrafficBlock
    End User NotificationShow
    Leave other criteria at default; save and activate.
  6. On Corp: Client PC confirm ZCC Internet Security is enabled. Browse to https://dlptoolbox.com/ → File Audit, upload Desktop → DLP Test Files → Sensitive Data.txt, and verify the upload is blocked.
