Lab 7

Configure DNS Security

Steer DNS through Zscaler, create DNS policy, and verify enforcement in DNS insights.

Time: ~20 minutesTasks: 3Outcome: Gambling DNS requests blocked and logged

7.1

Configure the Windows App Profile for DNS

Update the existing Windows app profile so all DNS domains are included for Zscaler DNS steering.

Current Experience Center navigation
Infrastructure›Connectors›Client›Platform Settings›Windows
  1. Open
    Infrastructure›Connectors›Client›Platform Settings›Windows
    Edit the HandsOnLab Windows policy.
  2. Under Traffic Steering → DNS, add * to Domain Inclusion, choose Create "*", and save.
  3. On Corp: Client PC open ZCC → More → Update Policy.
✓
Expected result

The Windows policy includes all DNS domains and the endpoint has refreshed its policy.

7.2

Configure a DNS Control Policy

Create a DNS rule that blocks the Gambling category.

Current Experience Center navigation
Internet Access›Policy›DNS Control
  1. Before the change, run nslookup www.gambling.com and confirm it resolves.
  2. Open
    Internet Access›Policy›DNS Control
    Review the predefined rules, then select Add DNS Filtering Rule.
  3. Configure:
    SettingValue
    Rule Order1
    Rule NameBlock Gambling
    Rule StatusEnabled
    DNS Request CategoriesGambling
    DNS Response CategoriesGambling
    Network TrafficBlock
    Save and Activate.
  4. Run nslookup www.google.com and confirm normal DNS still works. Then run ipconfig /flushdns followed by nslookup www.gambling.com 8.8.8.8. The gambling lookup should time out/fail.
✓
Expected result

Legitimate DNS resolves; gambling-category DNS is blocked.

7.3

View DNS Insight Logs

Confirm that the DNS policy hit is visible in logging/insights.

Current Experience Center navigation

Fastest option: use Search menu and search for DNS Insights.

  1. Use Search menu to open DNS Insights (or the DNS logs view available in Data Explorer).
  2. Set Timeframe to Current Day, add filter Rule Name = Block Gambling, and apply the filter.
  3. Verify gambling-domain requests are associated with the Block Gambling rule and a blocking action. If no events appear immediately, continue and return after log ingestion.
i
Keep in mind

DNS log ingestion may take roughly 15 minutes in the lab tenant.

✓
Expected result

DNS Insights shows hits on the Block Gambling rule.

✓
Lab 7 complete

Gambling DNS requests blocked and logged
