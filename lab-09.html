Lab 9

Provision ZPA Infrastructure

Create an App Connector group and provisioning key, then activate the pre-installed connector.

Time: ~25 minutesTasks: 2Outcome: App Connector registered and healthy
i
Use your assigned tenant

Use the Student ID, Student FQDN, session password, and Skytap link from your own lab-access email. Values shown in examples and screenshots are not your live credentials.

9.1

Provision an App Connector

Create the logical connector group and a provisioning key for the pre-installed App Connector VM.

Current Experience Center navigation
Infrastructure›Private Access›App Connector Groups
  1. On Corp: Win Svr 2016, sign in as PATRAINING\Administrator / Admin-123!, then sign in to https://console.zscaler.com/ as the student administrator.
  2. Open
    Infrastructure›Private Access›App Connector Groups
    and add a group:
    SettingValue
    NameOnPrem
    StatusEnabled
    Signing CertificateConnector
    DNS SettingsDefaults
    LocationNYC, NY, USA
    Version ProfileDefault
    Software Update ScheduleSunday 00:30
  3. Create an App Connector Provisioning Key for Group OnPrem: Name = OnPrem, Maximum Reuse Count = 4, Signing Certificate = Connector. Save.
  4. Copy the provisioning key. On the Windows Server desktop create a text file named exactly provision_key (no .txt extension), paste the key, and save.
i
Keep in mind

Use the Windows Server for this task because the next step transfers the provisioning key to the App Connector with WinSCP.

✓
Expected result

OnPrem App Connector Group exists and the provision_key file contains the session-specific provisioning key.

9.2

Activate the App Connector

Transfer the provisioning key to the connector VM, start the connector, and verify registration.

Current Experience Center navigation
Infrastructure›Private Access›App Connectors
  1. Log in to Corp: App Connector as admin / zscaler. Start SSH with sudo systemctl start sshd and verify sudo systemctl status sshd shows active (running).
  2. On Corp: Win Svr 2016 open WinSCP and connect to 10.0.0.4:22 as admin / zscaler. Upload provision_key from the Windows desktop to /home/admin.
  3. On the App Connector run pwd (expect /home/admin) and ls (expect provision_key).
  4. Activate the connector in this order: sudo systemctl stop zpa-connector → sudo cp provision_key /opt/zscaler/var/ → sudo ls /opt/zscaler/var/ → sudo systemctl start zpa-connector → sudo systemctl enable zpa-connector → sudo systemctl status zpa-connector.
  5. Back in Experience Center open
    Infrastructure›Private Access›App Connectors
    and confirm the connector is listed. Expand it to review host OS, Private Service Edge, location, IPs, and uptime.
i
Keep in mind

If activation fails, stop zpa-connector, clear /opt/zscaler/var, recopy provision_key, and start the service again. The source guide includes this recovery only for a red/failed connector.

✓
Expected result

The App Connector service is active and the connector appears in the ZPA infrastructure list.

✓
Lab 9 complete

App Connector registered and healthy
