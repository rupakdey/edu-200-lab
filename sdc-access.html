Checkpoint · Before Lab 14

Sign in to the Solutions Demo Center

Labs 14–16 use the read-only Solutions Demo Center. Find session-specific SDC credentials in the CloudShare Credentials panel, then sign in through Experience Center.

Applies to: Labs 14–16Access: Read-onlyConfiguration: Pre-built
!
Do not use your learner tenant for Labs 14–16

The Solutions Demo Center (SDC) is separate from the unique tenant you used in Labs 1–13. You are not expected to create or modify configuration in SDC.

What you need

Use the SDC credentials from CloudShare → Credentials

The CloudShare Credentials panel lists your assigned SDC identities. For these tasks, use the SDC administrator credentials unless a step specifies another user.

Use these fields

  1. Admin User Login URL — open the administrator SDC sign-in page shown in CloudShare → Credentials.
  2. Admin Username — use the assigned SDC administrator account.
  3. Password — use the shared SDC password shown in the same credential block.
  4. Complete 2FA enrollment if the environment prompts for it.
i
Other SDC usernames in CloudShare

HR, IT, Marketing, Sales, Contractor, and other non-admin identities may be listed for demonstration scenarios. Use them only when a specific lab step tells you to.
