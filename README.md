# EDU-200 Zscaler for Users – Administrator | Web Lab Guide (Rev 3.0)

An unofficial, web-friendly adaptation of the user-supplied Zscaler EDU-200 Administrator Hands-on Lab Guide, **October 2026 Revision 3.0**.

## Use

Serve the repository with `python3 -m http.server 8000` and open `http://localhost:8000/index.html`.

The guide includes 16 labs, a dedicated Solutions Demo Center access checkpoint before Lab 14, an independent ZPA concepts page, theme-aware topology, verified menu paths where available, Search Menu alternatives, task completion, dark mode, and click-to-expand screenshots.

For changes relative to the prior web version, see `REV3_CHANGELOG.md`. For generated-file checks, see `REV3_BUILD_REPORT.json`.
