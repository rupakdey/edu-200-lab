Lab 6

Configure Content Filtering & Access Control

Review threat protections, enforce URL categories, and apply cloud-app controls.

Time: ~25 minutesTasks: 4Outcome: Risky categories blocked; YouTube selectively allowed
i
Use your assigned tenant

Use the Student ID, Student FQDN, session password, and Skytap link from your own lab-access email. Values shown in examples and screenshots are not your live credentials.

6.1

View Threat Protection Settings

Review the tenant’s existing cyberthreat protections before creating access-control policy.

Current Experience Center navigation

Fastest option: use Search menu and search for Malware Protection / Advanced Threat Protection.

  1. Use Search menu and open Malware Protection. Compare enabled settings with the Recommended Policy indicators.
  2. Use Search menu and open Advanced Threat Protection. Review protections for command-and-control, phishing, cryptomining, tunneling, XSS, and related threats.
  3. Locate Suspicious Content Protection (Page Risk™) and review how the page-risk score is used to evaluate suspicious pages.
✓
Expected result

You have identified the threat-protection baseline already enabled in the tenant.

6.2

Configure Content Filtering Controls

Create a URL Filtering rule that blocks several high-risk or non-business categories.

Current Experience Center navigation
Internet Access›Policy›URL Filtering
  1. Before the change, browse to https://888.com and note that the site is reachable.
  2. Open
    Internet Access›Policy›URL Filtering
    Select Add URL Filtering Rule.
  3. Configure:
    SettingValue
    Rule Order1
    Rule NameRisky URL Categories
    URL CategoriesAdult Materials; Shopping and Auctions; Gambling; Video Streaming
    Request Methods / ProtocolsAll
    ActionBlock
    Save and Activate.
✓
Expected result

The Risky URL Categories rule is enabled and blocks the selected categories.

6.3

Test End-User Experience with URL Filtering

Validate how the URL policy changes the end-user experience.

Current Experience Center navigation
Internet Access›Policy›URL Filtering
  1. Browse to https://888.com and https://ebay.com. Both should be blocked by the new rule.
  2. Test https://youtube.com or https://netflix.com. Video Streaming should also be blocked at this point.
  3. If results appear cached, retry in Incognito. If access is still unexpected, return to
    Internet Access›Policy›URL Filtering
    edit Risky URL Categories and confirm Rule Status = Enabled.
✓
Expected result

Gambling, shopping/auction, and video-streaming test sites are blocked.

6.4

Configure Cloud App Control

Add a more specific cloud-application rule that allows YouTube while the broader video-streaming URL category remains blocked.

Current Experience Center navigation

Fastest option: use Search menu and search for SaaS Application Control.

  1. Use Search menu to open SaaS Application Control (Cloud App Control), then choose Add → Streaming Media.
  2. Create:
    SettingValue
    Rule Order1
    Rule NameAllow YouTube
    Cloud ApplicationYouTube
    Application AccessAllow
    DescriptionAllow only YouTube
    Save and Activate.
  3. On Corp: Client PC, verify YouTube loads while another streaming site such as Netflix remains blocked.
i
Keep in mind

Cloud App Control is evaluated with higher priority than URL-category policy for this use case.

✓
Expected result

YouTube is allowed by the more specific cloud-app policy while the broader streaming category remains restricted.

✓
Lab 6 complete

Risky categories blocked; YouTube selectively allowed
